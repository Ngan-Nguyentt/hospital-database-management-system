# Hospital Database Management System

A relational database for hospital operations — patients, doctors, staff,
appointments, medical records, prescriptions, billing, and room assignments —
with a Power BI dashboard built on top for operational reporting.

## Highlights
- Full schema design with referential integrity across 10+ entities
- Seed data scripts for every table
- Role-based access (admin & users) setup
- Business-question SQL answering real operational queries
- Power BI dashboard for visual analytics

## Tech
SQL · relational database design · Power BI

## Structure
Run the SQL scripts in numbered order:

1. `1. Create table.sql` — schema
2. `2.`–`12.` — insert seed data (departments, patients, doctors, appointments, records, etc.)
3. `13. Create admin & users.sql` — roles & permissions
4. `14. Business Question.sql` — analytical queries
5. `DB_Hospital_Database_Management_System_Dashboard.pbix` — Power BI dashboard
